# Auxiliary material

This directory contains material that is useful for historical reference but is not required by the active training, evaluation, or testing workflows.

| Path | Purpose |
| --- | --- |
| `.codex` | Empty historical placeholder; it contains no Codex configuration. |
| `code.zip` | Snapshot of an earlier version of the source tree. The maintained code is in the repository root, `src/`, `scripts/`, and `tests/`. |
| `refactor/` | Historical code-review and refactoring notes. |
| `research-wiki/` | Literature notes, research ideas, and a generated topic index. These notes provide research context but are not runtime inputs. |

Moving these items here does not change the experiment entry points. Active documentation remains in `docs/`, while generated and curated experiment reports remain in `reports/` because the code and configuration use that path.
